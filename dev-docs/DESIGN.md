# 设置界面设计规范

本文件定义 `client/client.js` 设置弹窗的视觉规则。后续改动优先复用这些 token，不再临时写字号、颜色或控件样式。

## 1. 颜色角色

| 角色 | Token | 用途 |
|---|---|---|
| 主文字 | `TEXT` | 正文、可编辑内容、标题 |
| 次级文字 | `MUTED` | 字段标签、只读提示词、库的辅助信息 |
| 三级文字 | `FAINT` | 说明、备注、元信息、导航说明 |
| 主强调 | `ACCENT` | 主按钮、当前状态、可编辑标记 |
| 成功 | `#2f8f5b` | 已保存、可用状态 |
| 错误 | `#d9534f` | 错误、不可用、危险操作 |
| 边框 | `BORDER` / `SOFT_BORDER` | 分割线、输入框、面板 |
| 产物状态 | `done #2e7d32` / `stale #b26a00` / `deck #1565c0` | 状态矩阵与版本列表的状态色，不参与按钮 |

规则：

- 红色只用于主操作、当前状态、可编辑强调。
- 普通选项的选中态用中性分段控件，不用红色。
- 说明文字使用 `FAINT`，不要和正文共用 `MUTED`。

## 2. 字体层级

代码中统一使用 `TYPE`：

| Token | 字号 / 行高 / 字重 | 用途 |
|---|---|---|
| `TYPE.display` | 20 / 1.3 / 650 | 页面标题 |
| `TYPE.brand` | 18 / 1.3 / 650 | 侧栏品牌名 |
| `TYPE.section` | 13.5 / 1.45 / 650 | 模块标题 |
| `TYPE.item` | 13 / 1.5 / 650 | 列表项标题 |
| `TYPE.body` | 12.5 / 1.75 / 400 | 正文、输入内容 |
| `TYPE.prompt` | 12.5 / 1.8 / 400 | 提示词正文，含只读和可编辑 |
| `TYPE.label` | 11 / 1.5 / 500 | 字段标签 |
| `TYPE.caption` | 10.5 / 1.65 / 400 | 说明、备注 |
| `TYPE.meta` | 9.5 / 1.5 / 500 | 元信息、路径、计数 |
| `TYPE.control` | 11.5 / 1.5 / 500 | 分段控件 |

规则：

- 所有提示词正文使用 `TYPE.prompt`，只通过颜色区分“只读 / 可编辑”。
- 备注和说明使用 `TYPE.caption + FAINT`，不能只靠字号小来区分。
- 字段标签使用 `TYPE.label + MUTED`。
- 技术路径默认继承界面字体，字号和颜色使用 `TYPE.meta + FAINT`；只有代码块才使用等宽字体。

## 3. 只读 / 可编辑

### 只读

- 使用普通文本，不使用输入框边框和输入框背景。
- 颜色使用 `MUTED`，与可编辑正文区分。
- 只读提示词块使用与“实际发送内容”相同的纸张面板：
  - 面板头部：`实际发送内容` + `只读` chip
  - 面板正文：`TYPE.prompt + MUTED`
- 不要使用左侧竖线、引用线或临时装饰。

### 可编辑

- 使用标准输入框 / 文本域：边框、背景、圆角、内边距一致。
- 输入内容使用 `TEXT` 和 `TYPE.body`。
- 技能名使用内联输入框，必须有清楚的边框和背景，不能只用下划线或透明文本。
- 可编辑控件不能放在“实际发送内容”的只读叙述里；检测等全局操作放在面板外，字段级“恢复默认”可以紧贴字段标签，但不能伪装成发送内容。

## 4. 组件规则

### 分段控件

- 所有“多选一”的选项统一使用 `renderSegmented`。
- 包括：内容生成方式、目标格式、版式取舍规则。
- 选中态使用中性表面和边框，不使用红色填充。

### 按钮

- 主按钮：保存、构建等唯一主操作，红色实心。
- 次按钮：取消、目录选择、检测、恢复默认，透明或浅描边。
- 危险操作：红色文字，不用红色大按钮。

### 导航

- 使用 Lucide 图标，不画 Unicode 字符或手绘 SVG。
- 图标使用 28×28 圆形底座；非当前项为中性浅底，当前项为主红色渐变圆底、白色图标。
- 当前项使用背景、文字提亮和红色渐变圆形图标，不使用竖线。
- 导航说明使用 `TYPE.caption + FAINT`。

### 面板

- 一个页面最多使用一个主纸张面板承载一个编辑任务。
- 避免卡片套卡片；模块之间用留白和分割线。
- 面板圆角 10，弹窗圆角 14。
- 只读和可编辑如果放在同一个面板，必须有明确的分区标题。

## 5. 禁止事项

- 不新增临时 `fontSize` / `color` 组合；先扩展 `TYPE` 或颜色角色。
- 不用红色表示普通 tab / 选项选中。
- 不用输入框外观展示只读内容。
- 不用引用线作为只读内容的唯一提示；只读内容统一用纸张面板 + `只读` chip。
- 不在设置弹窗整体背景上使用红色渐变；红色渐变只用于当前导航图标。
- 不把操作按钮放进实际发送提示词正文。
- 不在导航里使用系统 emoji 或自绘图标。
