# HTML路线：直接交付可打开的页面

## 路线与输出

本技能固定为 HTML 路线，不再询问。Agent 负责主体布局，可精确安排区域、比例、字阶、关系线和表格。交付的是 HTML/CSS 原生排版，不是把整页截图放进网页。默认一页一个独立 `.html`，不额外发 PNG。

使用参考库的检索和视觉查看流程。按本次内容设计，保持单色、高密度、多图示及参考品质，允许原创。具体排版接口见 [制作接口](rendering.md)，文字规则见 [文字保真](copy-policy.md)。

沿用参考库 `style.json` 的视觉规范（先用 `style_profile.py` 读取）；没有 profile 时：纯白全页底色，黑字、单主色与局部平涂浅色；原生二维形状和清晰关系线为主。没有用户明确要求，不加照片、底图、场景插画、渐变、阴影或立体特效。使文字与图形可分辨，便于后续PPT重建。主色默认 `#AD0101`，用户有品牌色或 profile 时统一替换 CSS 变量。

## 制作

1. 用 `snapshot_source.py` 把本次原文原样保存为 `source.txt`；由 Agent 先完整理解、取词及审慎删词，形成上图文案，建立 `copy-plan.json` 并通过 `check_copy.py --page-file <源文案>`，人工阅读删减与关系。这与 imagegen 直接接收完整原文、自行取舍的方式不同；本技能不执行 imagegen。
2. 在工作区制作 `slide.html` 模板，1920×1080 CSS 画布。可见文字使用空 `data-copy` 节点，文字层级和 CSS 图示精确控制；只用本次授权素材，不用参考页截图作背景。
3. 运行 `export_html.py`，将来源切片实际写进 HTML，内嵌本地图片与 CSS 资源，加入随窗口等比缩放；审计写工作区。它不调用生图或网络服务，原文与计划只在制作阶段使用。

```text
python scripts/export_html.py --html <工作区>/slide.html --source <工作区>/source.txt --plan <工作区>/copy-plan.json --page-file <源文案> --output <工作区>/page-01.html --report <工作区>/P01.audit.json
```

导出器支持内联 CSS、SVG 关系图、本地样式表、本地图片和 CSS url 资源。远程依赖、srcset、CSS import 或自定义脚本需要先改成适合离线单页的形式，不能假定它是通用网页打包器。普通原生中文字体可用系统已安装字体；用户明确要求跨机器字体一致时再按许可处理字体资源。

## 验收

- 可用 `scripts/render_slide.py` 作内部排版检查与截图，但截图不是默认交付物。它优先用 Playwright 自带 Chromium，缺失时回退系统已安装浏览器，不下载浏览器。DSH 默认 workspace-write 沙箱会拦截浏览器子进程；要截图时先向用户说明，并申请一次更宽权限后运行。未获批就不做 agent 侧截图，改为静态检查 + 交付 HTML，请用户在 DSH 侧栏或浏览器里看，并如实说明未做像素级验收。
- 直接打开最终 `page-01.html`，不执行任何文字注入，确认每个 `data-copy` 的实际文本与计划完全一致。
- 在 1920×1080 和较小的常用窗口查看，确认完整 16:9 缩放、正文可读、内容不被截断。缩放整页不能重新改写或重排句子。DSH 侧栏交互预览会执行导出器加的缩放脚本；静态预览禁用脚本，可能只显示画布一部分。
- 断开外部资源请求或记录网络活动，确认无需 `source.txt`、JSON、Python、服务器或远程服务仍能显示。交付前实际查看最终页面及密集局部；未看时说明。
- 单文件优先；用户要多页时按要求提供多个 HTML 或本地入口，不能未经要求加网站导航界面。

交付 `.html` 链接，简述双击打开即可；DSH 里也可在右侧文档预览打开。除非用户要求，不交付内部截图、生成脚本、计划和审计。已有页面后续修改沿用 HTML 路线，不重复询问。
