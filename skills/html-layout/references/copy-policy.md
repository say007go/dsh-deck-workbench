# 文字保真

> 本技能固定为 HTML 路线。文中 imagegen 内容仅用于说明文字保真边界，不执行、不询问路线、不切换。

## 允许与禁止

原文保留：可以换行、分段、强调和移动文字块，不替换字词、改标点或调整句内语序。自然换行由排版实现，不重写文字。

取词：从本次原文提取一个连续短语作标签、小标题或重点。不得从多处拼出新标签；提取关键词不能取代全部实质说明。同一短语可以重复作标签。

删词：为布局删除不重要修饰或重复表达，剩余文字保持原顺序和原句关系。保留核心观点与必要解释，无须全文上图。HTML由Agent在排版前整理并记录删词；imagegen收到完整原文后自行取舍，Agent在生成后记录实际显示文字及删词理由。删后不通顺时恢复文字或换布局，不能靠改写修补，不跨句拼新结论。

禁止：同义替换、语序调整、总结升华、口号化、补主谓、补写总领段、增加事实结论、数字、步骤、角色、时间、动作、成果或承诺。不为某版式补齐三项四项；标题也不能擅自重写。用户明确批准的编号或导航标签可在其授权范围内保留，不将其解释为额外业务事实或扩大到其它页面。

例：原句“通过系统化的课程学习，帮助学员进一步提升团队管理能力。”

- 可显示“通过课程学习，帮助学员提升团队管理能力。”，删除“系统化的”“进一步”。
- 可提取“课程学习”“团队管理能力”。
- 不可改为“系统课程赋能管理者，实现团队效能跃升”。

## 语义保护

数字、单位、日期、名称、对象、归属、因果、比较基准、条件、例外、程度和服务承诺必须保持。尤其保护“不、仅、部分、拟、可、至少、不超过”等限定。自动检查只覆盖部分常见词，不能理解所有语义，需逐句复核。

图形也会改变含义：并列事项不能画成因果或先后；成果不能移到别的对象下；面积、进度、比例、位置和大小若暗示数量或排名，必须有原文依据。拆段落时保留条件与对象。

缺少标题或总领段时，先从原文挑选现成句或短语；无法选取时调整层级或说明缺文字，不自行概括。内容不足就合理留白，不从参考稿填充事实。

## 来源与覆盖

原文逐字保存为source.txt。HTML的copy-plan.json绑定SHA-256并在制作前校验；imagegen提示词完整包含source.txt并记录SHA-256，不先准备精选上图文案。以下范围接口用于HTML的制作前计划；imagegen在生成后记录实际文字与来源，不把预选计划作为生图输入。DSH 中用文件工具读写 source.txt 和 JSON，保持 UTF-8 与原始换行；不要用聊天文本重打一份。

来源位置采用Python Unicode码点的左闭右开区间，不是JS UTF-16索引或字节位置。HTML显示文字直接取切片，不再手打一份。

每一处非空白原文都归入某显示项的原文范围或有理由的明确省略。提取标签的origin只能是该短语本身，不能用大范围掩盖未显示正文。数字和条件不能借省略绕过保护。重要名称或完整条件可列入protected_ranges要求实际显示。

程序可核验来源、顺序、覆盖和部分受保护词，不能判断删除的重要性或语义是否完整。保真检查与人工阅读缺一不可。
