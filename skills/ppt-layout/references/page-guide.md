# 参考页选择指南

本技能不内置参考稿，也不预设参考库的页数、章节或页码。页数、版式分组和页面元数据以 `<参考库>/manifest.json`、`<参考库>/references/index.jsonl` 和 `page-index.jsonl` 为准；参考稿的页序与章节不是新方案的固定目录。

`<参考库>/references/page-signature.jsonl` 是构建器生成的**客观几何签名**（列组数、行组数、连接件数量、卡片数量、字号谱、零件尺寸样本），用于按结构检索与取件。用 `assets/build-kit/scan_parts.py` 检索，见 [快速路径](quickstart.md)；签名或页面图缺失时，先用工作台的参考库上传/重新构建流程补齐，不能在技能目录内补一份副本。

选择参考页时：

- 先按本页内容关系、信息量和图文组织需要检索候选，再打开清晰图目视判断；索引标签不能代替看图。
- 参考页只提供视觉语言、零件规格与信息密度，不提供当前项目的事实、结论或固定版式。
- 不按固定页码选页，也不默认每页使用同一组参考；页数变化后旧页码没有意义。
- 参考稿中的历史客户信息、指标、年份、人物和截图不得继承。
- 选中后记录具体观察与实际用途，成品必须与参考并排核对，不能只凭“配色相似”判断。
