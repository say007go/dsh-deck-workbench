# DSH 集成约定（imagegen）

本技能是纯指令 + 本地脚本 + 外部参考库，不 import 任何插件、不调用网络，只通过当前环境暴露的生图工具执行 imagegen 路线。

## 生图工具契约

当前实现是 `image_generate` 工具（由 `dsh-imagegen` 提供）：

| 技能概念 | 工具参数 | 说明 |
|---|---|---|
| 提示词全文 | `prompt` | 必须把 `imagegen-prompt.txt` 全文内联传入；插件不读文件 |
| 参考图 1–3 张 | `reference_images` | 绝对本地路径（参考库为 `.webp`）或 URL；本地图会被压缩并上传 COS |
| 保存位置 | `save_path` | 指向工作区；目标已存在会报错，不覆盖 |
| 尺寸 | `size` | 不传则用插件设置默认；只有用户明确指定时才传 |
| 后缀开关 | `enhance` | 传 `false` 可跳过插件配置的提示词后缀；默认按设置追加 |
| 续等 | `task_id` | 超时后用同一任务 ID 续等，不重新提交 |

调用前确认流程（插件强制）：

1. 先展示最终 prompt 全文、尺寸、模型、参考图来源、save_path。
2. 用确认问题给出“确认生成 / 修改 / 取消”；只有“确认生成”才调用。
3. 一次只生成一张；出图后先给用户看，等反馈再决定是否继续。
4. 提交后通常 1–4 分钟；超时不要重开任务，用 `task_id` 续等。
5. 插件会追加配置里的提示词后缀；确认时说明这一点。

工具不可用时：如实说明 imagegen 路线阻塞，提出安装生图能力或改用 HTML；不自行写 API 调用器、不索取密钥、不静默切换。

## 软耦合边界

- 不写死插件版本号、provider、模型名、API Key 或 COS 配置。
- 不读写插件配置文件，不自动安装/启用插件。
- 提示词模板是纯文本，与插件无关；`prepare_imagegen.py` 不调用任何网络或生图接口。
- 换用其它生图插件时，只需改本文件的“工具契约”一节和 `imagegen-mode.md` 的调用段；提示词模板与验收流程不变。
- 本地参考图会按当前插件行为压缩并上传；使用前告知用户，参考库可能含历史客户内容。

## 环境与权限

- Python：使用当前环境可用的解释器（`python` / `sys.executable`）；Pillow 等依赖按实际环境探测。不安装新依赖。
- 参考库：由 `scripts/reference_root.py` 解析，优先级 `--reference` → `DECK_REFERENCE_ROOT` → 工作台配置文件；未配置时脚本给出明确错误。
- 工作区：source、prompt、review、生成图都写本次会话工作目录，不写参考库。
- 看图与交付：`read_image` 查看 PNG/WebP；`present` 交付图片/文件卡片；不要用 markdown 图片内联 4K 大图。

## 命名与分发

- 技能目录名与 frontmatter `name` 都是 `image-layout`。
- 不携带参考页码、参考稿或客户素材；参考库由用户配置。
- 技能可独立安装；不依赖其它 skill 或插件才能加载。
